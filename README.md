# Китайские шашки

Реализация игры "Китайские шашки" на Java.

## Текущая реализация (консольная версия)

### Реализовано:
- Игровое поле с отображением в консоли
- Основные правила игры:
    - Ход на соседнюю клетку
    - Прыжки через фишки
    - Проверка корректности ходов
- Два режима игры:
    - Интерактивный (игрок vs бот)
    - Наблюдатель (бот vs бот)
- Таймер игры (5 минут)
- Система ходов по очереди
- Определение победителя

### Архитектура:
- `GameBoard` - игровое поле
- `GameRules` - правила игры
- `PlayerStrategy` - стратегии игроков
- `HumanPlayer` - игрок-человек
- `RandomBot` - бот со случайными ходами
