# Китайские шашки

Java-приложение для игры в китайские шашки с графическим интерфейсом Swing. Поддерживает два режима: игра против бота и наблюдение за ботами.

## Особенности

### Основной функционал
- **Два режима игры:**
  -  **Против бота** — игрок (красные) против компьютерного оппонента (синие)
  -  **Наблюдение** — два бота играют друг против друга автоматически
- **Полноценное игровое поле** в форме ромба 16×16, к сожалению
- **Прокрутка и перемещение** по полю мышкой
- **Таймер игры** — 5 минут на партию

### Механика игры
- **Красные (игрок)** — начинают в нижнем углу, цель — верхний угол
- **Синие (бот)** — начинают в верхнем углу, цель — нижний угол
- **10 шашек у каждого игрока**
- **Правила ходов:**
  - Шаг на соседнюю клетку (по вертикали, горизонтали, диагонали)
  - Прыжок через шашку (свою или противника)
- **Победа:** первый игрок, переместивший все 10 шашек в целевую зону
